# Marcas

Por defecto no hay marca: se usa el estilo del proyecto o el de la skill (`diseno.md`). Cuando el documento es para una organización con marca, **la marca decide todo lo visual** (colores, tipografía, layouts, logos, fotos) y esta skill sigue decidiendo el **contenido** (brief, mensaje, guion, nivel, largo y visuales).

## Cómo agregar una marca

1. **Crea una skill de marca aparte** (por ejemplo, `mi-empresa-design`) con lo que define cómo se ve: colores, tipografías (y sus archivos), logos, íconos, fotos de biblioteca, ejemplos de láminas y reglas ("el azul es el ancla", "fotos solo de la biblioteca", "sin degradados").
2. **Agrega aquí una sección por marca** con:
   - **Cuándo aplica:** qué palabras del pedido o qué carpetas la activan.
   - **Dónde está:** la ruta de la skill de marca y sus recursos.
   - **Precedentes:** presentaciones o informes ya aprobados con esa marca, para usarlos como base técnica en vez de partir de cero.
   - **Reglas que mandan sobre esta skill:** lo que la marca exige aunque contradiga `diseno.md` (por ejemplo, otra tipografía o bordes redondeados).
   - **Salidas:** formatos que la organización usa (PPTX, PDF) y dónde se guardan.
3. **Aplícala sobre las plantillas:** cambia las variables de la plantilla (`--B`, `--F`, `--M`, `--accent`, `--display`, `--sans`, `--r`) y agrega el logo; no rehagas la plantilla. El contenido sigue las reglas de siempre: conclusión primero, títulos-afirmación, largo según el pedido, nivel según el lector y un visual por idea.
